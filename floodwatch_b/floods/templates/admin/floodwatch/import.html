    How it works

    • Loose files are merged with the current data{% if has_current %} in {{ web_data_name }}/{% endif %}, so you only upload what changed.
    • Safe to repeat. Re-uploading the same data changes nothing, and nothing is ever deleted.

    • After importing, the files are saved as the current data (the previous version is backed up), so the daily update won't undo your import.
